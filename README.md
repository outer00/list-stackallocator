# List & StackAllocator

Двусвязный список, совместимый со стандартными аллокаторами, и `StackAllocator` - аллокатор поверх заранее выделенного буфера. Учебный проект курса C++ на ФПМИ МФТИ.

## Что реализовано

### List

Аналог `std::list`: кольцевой список с фиктивной вершиной, так что `begin()` и `end()` не требуют проверок на `nullptr`, а вставка и удаление в любом месте - за O(1).

- **Поддержка аллокаторов.** Список корректно обрабатывает `propagate_on_container_copy_assignment` и `select_on_container_copy_construction`, то есть переносит аллокатор между объектами только тогда, когда это разрешено трейтами. Память под узлы выделяется через `rebind`.
- **Безопасность исключений.** Если конструктор `T` бросает исключение при вставке или копировании списка, вся уже выделенная память освобождается.
- **Двунаправленные итераторы** с приведением неконстантного к константному.

### StackAllocator

Bump-аллокатор: `allocate` - это сдвиг указателя внутри буфера `StackStorage<N>`, `deallocate` не делает ничего. Выравнивание считается через `std::align`, `rebind` позволяет использовать аллокатор для узлов контейнера, а не только для `T`.

Расплата за скорость - память освобождается только целиком, вместе с хранилищем. Зато на сценарии из тестов (миллион вставок и удалений) это заметно быстрее стандартного аллокатора:

|                | std::list | List (эта реализация) |
|----------------|-----------|-----------------------|
| std::allocator | ~56 мс    | ~47 мс                |
| StackAllocator | ~18 мс    | ~11 мс                |

Замер из `tests.cpp` на GCC 13, `-O2`.

## Файлы

- `list.h` - список и итераторы.
- `stackallocator.h` - `StackStorage` и `StackAllocator`.
- `tests.cpp` - тесты курса: корректность операций, подсчёт конструкторов и деструкторов, поведение при исключениях, выравнивание, работа с `std::deque`, совместимость с трейтами аллокаторов и замер производительности.

## Сборка и запуск тестов

Тесты поднимают лимит стека через `setrlimit` (`<sys/resource.h>`), поэтому запускать их нужно на Linux или macOS: `StackStorage` в тестах занимает 200 МБ.

```bash
g++ -std=c++20 -O3 tests.cpp -o list_tests
./list_tests
```
