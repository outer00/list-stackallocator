# Custom Linked List & Stack Allocator (C++)

В этом репозитории реализован собственный двусвязный список `List` (аналог `std::list`), полностью совместимый со стандартными аллокаторами, а также `StackAllocator` — быстрый аллокатор памяти, работающий на заранее выделенном буфере (по принципу Bump-аллокации).
Проект демонстрирует глубокое понимание ручного управления памятью, выравнивания данных и концепции Allocator-Aware контейнеров в C++.

## ⚙️ Особенности реализации

### 1. Allocator-Aware `List`
* **Sentinel Node (Фиктивная нода):** Список реализован как кольцевой с использованием базового узла `BaseNode` без данных. Это избавляет от проверок на `nullptr` и делает методы `begin()` / `end()` максимально быстрыми. * **Allocator Propagation:** Реализована полная поддержка пользовательских аллокаторов. Список корректно обрабатывает свойства `propagate_on_container_copy_assignment` и `select_on_container_copy_construction`, перенося аллокаторы между объектами только когда это разрешено трейтсами.
* **Exception Safety:** Строгая гарантия безопасности исключений (Strong Exception Guarantee). Если конструктор типа `T` бросает исключение при вставке или копировании списка, вся уже выделенная память корректно очищается, не допуская утечек.
* **Итераторы:** Реализован `Bidirectional Iterator` с правильным преобразованием от `iterator` к `const_iterator`.

### 2. Fast `StackAllocator`
* **Bump Allocation:** Аллокатор работает поверх статического буфера `StackStorage<N>`. Выделение памяти (`allocate`) сводится к простому сдвигу указателя, что работает значительно быстрее стандартного вызова `new` / `malloc`.
* **Memory Alignment:** Поддерживается строгое выравнивание памяти в зависимости от типа `T` с использованием низкоуровневой функции `std::align`.
* **Rebind:** Реализован шаблон `rebind`, позволяющий контейнеру (например, `List` или `std::deque`) выделять память не только под сам тип `T`, но и под внутренние узлы.

## 🗂 Структура проекта

* `list.h` — реализация двусвязного списка и двунаправленных итераторов.
* `stackallocator.h` — реализация хранилища `StackStorage` и самого `StackAllocator`.
* `tests.cpp` — строгие юнит-тесты и бенчмарки.

### Что проверяют тесты:
1. Корректность работы итераторов и методов модификации.
2. Подсчет вызовов конструкторов/деструкторов для предотвращения утечек.
3. Безопасность при исключениях (имитация бросающих конструкторов).
4. Правильность выравнивания памяти (`Alignment`).
5. **Performance test:** Сравнение скорости работы связного списка со `std::allocator` и `StackAllocator` (аллокатор на стеке показывает прирост скорости).

## 🚀 Как собрать и запустить

⚠️ **Важно:** Тесты увеличивают лимит стека программы (RLIMIT_STACK) через системные вызовы POSIX (`<sys/resource.h>`), так как `StackStorage` может требовать сотни мегабайт памяти. Сборка и запуск тестов предполагаются в Linux/macOS.

```bash
# Компиляция (C++20)
g++ -std=c++20 -Wall -Wextra -O3 tests.cpp -o list_tests

# Запуск
./list_tests
